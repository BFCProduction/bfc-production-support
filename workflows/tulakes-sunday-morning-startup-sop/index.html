    Tulakes Sunday Morning Startup SOP

    Purpose

    Prepare the Tulakes room for Sunday morning service by confirming that the control computer, ProPresenter, projector, confidence monitor, audio console, microphone, and video routing are all ready before the Tulakes team arrives.

    Scope

    This procedure is for the early-morning setup of the Tulakes worship space in the other building on campus.

    Procedure

    1. Enter the room and verify the control computer is ready

    • Confirm the control computer is powered on.
    • Log in if needed.
    • Make sure the system is responsive before moving on.

    2. Confirm basic video system communication

    • Verify the video switcher is connected and responding.
    • Press a switcher button such as Cam 1 or Cam 2.
    • Watch the multiview monitor to confirm the switcher is functioning.

    3. Close unnecessary applications

    • Before starting service software, close any apps that do not need to be running.
    • Use Force Quit if necessary.
    • Common examples include Microsoft Update, Spotify, Chrome, or other background applications.
    • Leave only the applications required for service operation.

    4. Open ProPresenter and load the correct Tulakes playlist

    • Launch ProPresenter.
    • Open the most recent Tulakes service playlist.
    • Confirm you are in the correct service file before running any media.

    5. Start the walk-in content

    • In ProPresenter, locate the Tulakes walk-in content near the top of the playlist.
    • Trigger the walk-in item.
    • Use the multiview monitor to confirm ProPresenter is feeding the system properly.
    • Confirm the graphics path is reaching the projector feed, confidence feed, and stream path.

    6. Check the confidence display

    • Look at the confidence TV and confirm it is on.
    • If it is off, use the black Sony remote to power it on.

    7. Turn on the projector

    • Check whether the projector is on.
    • If it is off, use the white Sony projector remote.
    • Press the green On button while pointing the remote at the projector.
    • Confirm the projector begins powering up.

    8. Locate and test a handheld microphone

    • Find a handheld microphone, usually stored in the nearby drawer.
    • Power it on and check for battery life.
    • If the first mic is dead, try another mic.
    • If no working mic is available because of dead batteries, note the issue and leave battery replacement to the Tulakes team.
    • If a working mic is available, test it and confirm signal is reaching the console.

    9. Load the Tulakes audio console scene

    • Go to the audio console.
    • Press Scenes.
    • Use the arrow keys to move to the scene list.
    • Use the rotary knob to scroll to the Tulakes scene.
    • Select Load.
    • Confirm the load action.

    10. Leave the console in a useful operating state

    • Exit the scene screen after loading the Tulakes scene.
    • Do not leave the console parked in the Scenes menu.
    • Set the fader layers so both sides show something useful to the Tulakes team.
    • Set one side to Inputs 1-8 for microphones and primary inputs.
    • Set the other side to USB for clip playback.

    11. Verify playback audio from ProPresenter

    • Return to ProPresenter.
    • Play the Tulakes rolling video or other media playback item.
    • Bring up the appropriate faders on the console as needed.
    • Confirm that playback audio is reaching the console and functioning normally.

    12. Check media behavior if playback is abnormal

    • If playback stops early or behaves unexpectedly, inspect the media settings in ProPresenter.
    • Check the Inspector and confirm the stop point or playback settings are correct.
    • Correct any obvious issue and test playback again.

    13. Restart ProPresenter if necessary

    • If ProPresenter is still not behaving normally, force quit unnecessary applications again.
    • Reopen ProPresenter.
    • Reload the Tulakes playlist.
    • Re-test playback until the system behaves normally.

    14. Put the room on the Tulakes loop

    • Once ProPresenter is stable, put the system on the Tulakes loop or walk-in content.
    • Confirm the loop is visible on the projector.
    • Confirm the same graphics are visible on the confidence display.

    15. Verify ATEM output routing

    • Open ATEM Software Control.
    • Go to Outputs.
    • Confirm the Projector output is set to Graphics.
    • Confirm the Confidence output is set correctly for confidence graphics.
    • This ensures the room displays graphics rather than camera feeds.
    • Camera feeds should remain available for the stream, but they should not be shown in-room unless specifically needed.

    16. Perform the final ready check

    Before leaving the room, confirm all of the following:

    • Control computer is on and responsive
    • Video switcher is functioning
    • Unneeded applications are closed
    • ProPresenter is open to the correct Tulakes playlist
    • Walk-in or loop content is running
    • Confidence TV is on
    • Projector is on
    • Tulakes console scene is loaded
    • Console fader layers are left in a useful state
    • Playback audio is working
    • ATEM outputs are routed correctly
    • The room is ready for Tulakes service

    Troubleshooting Notes

    If ProPresenter is unstable

    • Force quit unnecessary apps first.
    • Reopen ProPresenter.
    • Reload the playlist.
    • Test again.

    If a microphone is dead

    • Try a second handheld mic.
    • If no working batteries are available, note the issue and leave replacement to the Tulakes team.

    If playback stops early

    • Check the media item in ProPresenter Inspector.
    • Confirm the stop point is set correctly.
    • Test again after adjusting.

    End State

    When this SOP is complete, Tulakes should walk into a room where:

    • graphics are already up
    • projector and confidence monitor are on
    • console is loaded and organized
    • stream routing is correct
    • the system is ready for service with minimal additional setup
