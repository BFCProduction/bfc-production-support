# Dana Dolly V3 Beltless — Is My Dolly Compatible?

*Source: [eMotimo Support](https://support.emotimo.com/hc/en-us/articles/39108161028621)*

The DDV3 Beltless integration kit uses a friction drive system and works with most Dana Dollies — but not all. Check the list below before purchasing or setting up.

---

## What Works

- **Round track with Universal Ends** using standard 1.66" nominal pipe diameter — this is 1¼" Schedule 40 or Schedule 80 aluminum pipe (Dana Dolly's recommended spec)
- Wheels must be **offset** so one wheel reaches the end before the other (when viewed from above)

## What Does NOT Work

| Issue | Notes |
|---|---|
| **Original Track Ends** | Works on boxes/floor, but dangerous on stands — the dolly can fly over the end stops at speed. Add a mechanical stop before using. |
| **Non-standard pipe diameter** (e.g. 50mm OD / 1.97" common in Europe) | Carriage rides too high for motor wheel contact. Contact eMotimo — they have a solution. |
| **Triangle Track** | Ride height and friction issues, no workaround. |
| **Dana Dolly knock-offs** | No support possible with third-party dollies. |
| **High Hat Dana Dolly version** | Not compatible. |
| **Very old carriages with non-offset wheel sets** | Sensor boards and motor will impact these wheels. |
