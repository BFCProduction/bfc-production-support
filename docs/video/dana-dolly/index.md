# Dana Dolly V3 Beltless Integration

The DDV3 Beltless kit motorizes the Dana Dolly using a friction drive system, enabling controlled single-pass and ping-pong interview shots on short and long runs. It works with the eMotimo Spectrum ST4/ST4.3 and Conductor SA2.6.
