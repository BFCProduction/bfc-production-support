# PTZ Operator Instructions

This page explains the PTZ controller interface, how to move the camera, how to save presets, and where to find key controls for focus, dolly limits, and roll.

---

## Select the Camera

- Select the desired camera using the camera buttons along the bottom of the controller.

## Reboot the Controller

- To reboot the controller, unplug the network cable and plug it back in.
- The controller will take several minutes to reboot.

---

## Home Menu

- `Connected` button: Near the upper left. Shows green if connected to the selected camera or red if not connected.
- `Focus OneShot` button: To the right of the `Connected` button. This only appears when `PTZ Camera 7` is selected. Press it to set focus.
- `Preset Number` dial: Select the preset to use. Also works with run time and ramp time when manually selecting a preset.
- `Run Time` dial: Sets the preset speed in seconds. A smaller number moves the camera faster.
- `Ramp Time` dial: Sets how quickly the camera gets up to speed. A smaller number gets up to speed faster.

## Presets Menu

- This is the same as the Home menu.

## Loops Menu

- `Loop Number` dial: Select the loop number you want to set.
- `Loop Run Time` dial: Sets the speed for the loop in seconds. A smaller number moves the camera faster.
- `Loop Ramp Time` dial: Sets how quickly the camera gets up to speed. A smaller number gets up to speed faster.
- `A Point` dial: Select the preset for the left side of the dolly.
- `B Point` dial: Select the preset for the right side of the dolly.
- `Start/Stop Loop` dial: Press to start the selected loop, or press and hold to stop the selected loop.
- `Roll Speed` dial: Sets the left/right tilt of the camera. Turn the dial in either direction to start tilting, then turn the dial the other direction to stop the tilt. Go one notch at a time, because the faster you turn the knob the faster you have to turn it back to make it stop.

## Motors Menu

- Use this menu to set the left/right limits on the dolly.
- Use `PTZ Camera 7` to view `Camera 3` and the dolly so you can see how close the camera is to the end of the dolly.
- Move the camera near one end of the dolly and press `Stop A Slide`.
- Move the camera near the other end of the dolly and press `Stop B Slide`.

## FIZ Menu

- `TN Focus Position` dial: This is the second dial from the left.
- Turn it all the way back to zero, then turn it up until the camera is focused.
- Always start at zero.

---

## Presets Info

- Presets can be set from either the Home menu or the Presets menu.
- Presets shown in green already have a preset saved.
- Presets not shown in green are blank.

## To Set Presets

1. Select the camera.
2. Focus the camera.
3. Move the camera to the end of the dolly.
4. Set zoom and position.
5. Press and hold the appropriate preset number for 2 seconds. The button will blink to confirm the save.
6. Continue until all presets are set.

## To Move the Camera

- Start a loop.
- Or select a preset to move the camera.
- You do not need to stop a loop before selecting a preset.

---

## Index

- Focus: `FIZ Menu` → Top Row → `Focus Position`
- Limits: `Motors Menu` → Middle Row → `Stop A Slide` / `Stop B Slide`
- Roll: `Loops Menu` → Top Row → Top Right `Roll Speed`
