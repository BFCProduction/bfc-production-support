# Dana Dolly V3 Beltless — Firmware

*Source: [eMotimo Support](https://support.emotimo.com/hc/en-us/articles/38847252701709)*

Sensor reading was significantly improved in firmware updates released in mid-August 2025. Before setting up the DDV3 Beltless kit, make sure both devices are on the latest firmware.

---

## Required Updates

- **Spectrum ST4 / ST4.3** — update to the latest beta firmware
- **Conductor SA2.6** — update to the latest beta firmware

See the eMotimo support site for current release notes and download links:

- [Spectrum ST4 Firmware page](https://support.emotimo.com)
- [Conductor SA2.6 Firmware page](https://support.emotimo.com)

!!! warning
    Do not proceed with sensor or calibration setup until both units are on current firmware. Outdated firmware will cause unreliable sensor readings.
