# Dana Dolly V3 Beltless — Physical Install

*Source: [eMotimo Support](https://support.emotimo.com/hc/en-us/articles/36668560223117)*

This article covers mounting the DDV3 Beltless motor unit to the Dana Dolly carriage. The primary reference is the eMotimo install video — the steps below summarize the key points.

---

## Install Video

Watch the eMotimo install video at the [source article](https://support.emotimo.com/hc/en-us/articles/36668560223117) (Instagram embed). The first 30 seconds of the video shows the motor mounted with the Conductor SA2.6 — the physical mounting is the same for Spectrum ST4 setups.

---

## Key Point: Engaging the Motor

After mounting, the drive wheel must be **engaged** before it will make contact with the speed rail:

- Pull the **silver locking pin** — this releases the motor from its locked (disengaged) position
- The drive wheel will drop down and make firm contact with the track

See [Engaging and Disengaging the Motor](dana-dolly-v3-motor-engage.md) for full details.
